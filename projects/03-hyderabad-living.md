# Hyderabad Living – Furniture E-Commerce Platform

**Project:** Hyderabad Living  
**Category:** E-Commerce Website Development  
**Technology:** Shopify Liquid, HTML, CSS, JavaScript, JSON, Node.js  
**Project Type:** Furniture E-Commerce Storefront  
**Status:** Frontend implementation completed; production integrations pending.

## Project Overview

Hyderabad Living is a responsive furniture e-commerce platform designed to provide customers with a convenient online furniture-shopping experience.

The project focuses on modern storefront design, product discovery, detailed product pages, shopping cart functionality, customer account interfaces and a simplified checkout experience.

The storefront uses Shopify Online Store 2.0 theme architecture with reusable Liquid sections and custom JavaScript functionality.

## Key Features

### 1. Homepage and Storefront
- Full-width photographic hero section.
- Furniture category navigation.

- Room-based promotional sections.

### 5. Checkout and Order Experience

### 6. Responsive Design and Accessibility
- Mobile-first responsive layouts.

## Integration Scope

The frontend includes documented integration points for:

- Google Identity Services – sign-in flow.
- Cashfree Payments – hosted checkout.
- Delhivery – delivery serviceability and shipping quotes.

**Important:** These are integration targets, not completed production integrations. A production backend, database, payment verification, authentication infrastructure and live shipment booking are not included in this project package.
